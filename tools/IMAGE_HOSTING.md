# 图片优先服务器、失败回退与本地上传

## 写文章时怎么用

双击仓库根目录的 `图片上传工具.cmd`，浏览器会打开本机工具。也可在工具运行期间访问 <http://127.0.0.1:4318/>。

1. 选择或输入文章分类，填写独立的文章图片目录。
2. 拖入图片或点“选择图片”，再点“保存并上传”。单批最多 100 张、50 MB。
3. 上传成功后复制 Markdown 放入文章。工具同时返回服务器网址、服务器目录和备用网址。
4. 将文章与工具保存在 `source/images/<分类>/<文章目录>/` 的图片一起提交，按原流程发布博客。仅上传服务器，不等于已经发布备用副本。

已有图片不会批量删除。同名且内容不同的本地文件会拒绝覆盖，请使用新名字。相同内容可重复上传，rsync 会跳过未变化的数据。工具不会发布文章或启用账号、评论。

文章建议保持 `![](/images/文章目录/图片.png)`；工具输出会对中文等字符正确编码。不要为了使用图床把文章永久改为只有服务器绝对地址：发布流程会自动转换页面，源文章仍可在本地预览。

把仓库 `source/images` 内的图片、目录，或 Markdown 文章拖到 `图片上传工具.cmd` 上，也可以直接上传。对于文章，工具只选择文章引用的图片，不会顺带上传其他草稿。

```powershell
# 先查看文章会上传哪些图片
node tools/upload_images.js "source/_posts/物理学/你的文章.md" --dry-run
# 上传文章所用图片，并将可识别的图片引用规范成 /images/... 相对路径
node tools/upload_images.js "source/_posts/物理学/你的文章.md" --write
```

`--write` 只在上传成功后生效，改写前自动备份到 `tmp/community-uploads/backups/`。上传期间如果原文被其他编辑器修改，会跳过改写。默认不修改文章；外部网站图片也不会被擅自下载或转换。上传记录保存在 `tmp/community-uploads/`。

## 访客读图

- 构建页面中的图片优先使用 `https://img.apc-science.cn`。原图片继续留在静态站点中，同路径不再强制跳转到图片服务器。
- 普通图片、动态插入的图片、响应式 picture/srcset、内联背景图失败时回退到站点同路径图片，不来回重试。
- 服务器明确返回错误立即回退；8 秒内仍未取得图片尺寸则回退。已经开始到达的大图允许继续下载，最长等到约 60 秒，避免 5 Mbps 服务器的大图误触发回退。
- 原生延迟加载图片接近视口后才开始超时计时。错误地址短暂记忆 60 秒；10 秒内 3 个不同地址失败，则本标签页短暂优先备用站点，减少逐图等待。刷新/页面切换通过 sessionStorage 保留这段短期状态，存储不可用时仍可回退。
- 正常加载不会同时下载服务器和备用站点两份图片，也不额外先做健康检查。内联背景图的检查复用浏览器图片缓存。独立游戏/不包含主题脚本的页面以及样式表内的小图片保留站点原路径。
- 回退依赖静态站点自身可访问。它提高可用性，但不能解决服务器和网站托管同时不可用的情况。未发布的本地电脑文件当然不能直接被访客读取。

## 本机配置与权限

当前电脑已配置 `.image-upload.local.json`（已加入忽略，不提交仓库）。它只记录工具和已有密钥文件的位置，不把私钥内容写进网页。不要把该文件、密钥或整个 tmp 目录发布到网站。

换电脑时安装 Node.js 24、rsync/SSH，并使用获授权的受限部署密钥与已核对的 known_hosts；配置示例：

```json
{
  "host": "服务器地址",
  "user": "apc-publish",
  "imageOrigin": "https://img.apc-science.cn",
  "siteOrigin": "https://apc-science.cn",
  "keyFile": "私钥绝对路径",
  "knownHostsFile": "已核对的 known_hosts 绝对路径",
  "rsync": "rsync 可执行文件绝对路径",
  "ssh": "ssh 可执行文件绝对路径",
  "runtimePath": "Windows 下 MSYS2 运行库和 Git usr/bin 的目录，以分号分隔"
}
```

当前 Windows 使用此前从官方 MSYS2 下载并核对 SHA-256 的隔离运行库，不修改 Git 安装。运行库与现有密钥位于 `tmp/community-deploy/`，不要误清理；需要搬迁时同步修改本机配置。SSH 始终验证主机身份，使用已有受限 `apc-publish` 账号，不增加服务器权限、不读取账号数据库或邮件密钥。

网页工具只监听 `127.0.0.1`，检查 Host、Origin、随机请求令牌并拒绝跨站上传。关闭运行窗口即停止服务。上传前会保留本地文件，传输后核对公网图片状态与大小；中途失败可重试。

