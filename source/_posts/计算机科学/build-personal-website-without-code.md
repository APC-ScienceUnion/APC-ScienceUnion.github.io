Would you like a blog or résumé site of your own? A personal corner of the internet gives you room to experiment and build something that is entirely yours. This guide shows complete beginners how to set one up **quickly and easily**, without writing code.

#	Create a GitHub account

GitHub is an open-source code-hosting platform where people share and manage projects. If you do not have an account yet, follow the steps below. Otherwise, skip to the next section.

### How do I sign up for GitHub?
1. Open the GitHub website
Open a browser and go to https://github.com/.
2. Complete the registration form
On the GitHub home page, click “Sign up” in the upper-right corner. Enter a username, an email address, and a password. Use a valid email address because GitHub will ask you to verify it. When the form is complete, click “Create an account.”
3. Verify your email address
GitHub will send a verification message to the address you entered. Open the message and click “Verify email address” to complete your registration.

# Create your personal website
Open the project you chose in the previous section. In the academic résumé example, the “Fork” button appears in the upper-right corner of the project page:

<img src="/images/%E7%AE%80%E5%8E%86%E7%BD%91%E7%AB%99%EF%BC%9F/fig-002-25b72d419b.jpg" alt="image.png" title="image.png" />

Click Fork, then open the repository that GitHub creates under your account. In its settings, rename the repository to yourusername.github.io, replacing yourusername with your GitHub username.

> Note: Keep .github.io exactly as written. Replace only yourusername.

<img src="/images/%E7%AE%80%E5%8E%86%E7%BD%91%E7%AB%99%EF%BC%9F/fig-003-703db4c669.jpg" alt="image.png" title="image.png" />

# Customize the site

Enter yourusername.github.io in a browser, again replacing yourusername with your GitHub username, to open the site. For the academic résumé template, the README explains how to customize it:

<img src="/images/%E7%AE%80%E5%8E%86%E7%BD%91%E7%AB%99%EF%BC%9F/fig-004-f16d2fba80.jpg" alt="image.png" title="image.png" />

The instructions look like this:

<img src="/images/%E7%AE%80%E5%8E%86%E7%BD%91%E7%AB%99%EF%BC%9F/fig-005-46fdda72a6.jpg" alt="image.png" title="image.png" />

To change a page, open its corresponding file in the repository and click the edit button:

<img src="/images/%E7%AE%80%E5%8E%86%E7%BD%91%E7%AB%99%EF%BC%9F/fig-006-7bef1843fe.jpg" alt="image.png" title="image.png" />

Once you have edited the page, click Commit to save the change. Give the site a little time to deploy, then reload it in your browser. The new content should appear.

<img src="/images/%E7%AE%80%E5%8E%86%E7%BD%91%E7%AB%99%EF%BC%9F/fig-007-f8e944cf80.jpg" alt="image.png" title="image.png" />

You can also upload files of your own, including PDFs and images; the README explains how. From there, explore the template and learn how its styles work. With a little experimentation, you will have an academic résumé site of your own.

> Can I use a domain name of my own?
Yes, but you would need to buy the domain. Because that option is not free, this article does not cover it.
